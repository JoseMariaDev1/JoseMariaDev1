- 🪐 **Antigravity**: uso de agentes de IA para planificar y ejecutar tareas de desarrollo de principio a fin, desde la implementación hasta la verificación.

**📝 Specs: desarrollo guiado por especificaciones**

Antes de escribir código, defino la especificación del problema. Así la IA genera resultados más precisos y el código queda documentado.

1. **Requisitos**: qué debe hacer la funcionalidad y qué casos límite contempla.
2. **Diseño**: arquitectura, modelos de datos y contratos de API.
3. **Tareas**: lista de pasos pequeños y verificables.

Este flujo reduce las iteraciones con la IA, mejora la trazabilidad de los cambios y facilita el mantenimiento.
